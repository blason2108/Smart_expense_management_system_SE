## Objective

|---|---|---|---|

| CB-02 | Dashboard | Open the dashboard | Financial summary and budget information display correctly |
| CB-03 | Categories | Open the categories page | Categories load without layout problems |
| CB-04 | Transactions | Add, edit and delete a test transaction | Changes are saved and reflected correctly |

| CB-10 | Usability | Inspect labels, buttons, forms and error messages | Controls are understandable and usable |
